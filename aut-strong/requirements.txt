# aut-naive dependencies - DELIBERATELY SEPARATE from the harness.
# DESIGN.md 1.4: "Separate repo directory, separate container, own Dockerfile."
# and "The harness talks to both over HTTP only. No shared imports."
#
# Nothing here may be imported by harness/, and nothing in harness/ may be
# imported here. If these two files ever start converging, the frozen-agent
# claim (commitment C3) is compromised.
#
# sentence-transformers and faiss-cpu are the "(AUT only)" entries from the
# DESIGN.md Appendix.
#
# ---------------------------------------------------------------------------
# WHY EVERY VERSION IS PINNED, INCLUDING TRANSITIVE ONES
#
# Commitment C3 freezes the agent "by commit SHA". A SHA only freezes the code.
# Resolve this file six weeks from now with floating versions and you get the
# same SHA running different software: a new `transformers` changes tokenisation,
# a new `sentence-transformers` changes pooling, and top-k retrieval moves
# without a single tracked byte changing. The audit trail would attribute that
# drift to the agent. So the pins are the other half of the freeze, and
# transitive deps are pinned too - `sentence-transformers==6.0.0` does not
# constrain `transformers` tightly enough to matter.
#
# These versions are NOT hand-written. They are `pip freeze` from a real build
# of this exact Dockerfile (harvested 2026-08-22 via a throwaway
# `clauseguard/pin-probe:tmp` image, which self-reports "(unfrozen)" because it
# is built without the freeze ARGs). Re-harvest the same way after any
# deliberate upgrade; never edit a version here by hand.
#
# Two packages are deliberately absent:
#   torch      - installed in the Dockerfile from the PyTorch CPU index, because
#                the resolved build is 2.13.0+cpu and that local-version segment
#                does not exist on PyPI. Pinned there, on that line.
#   setuptools - ships with the base image; pinning it here would reinstall
#                build tooling as though it were a runtime dependency.
# ---------------------------------------------------------------------------
